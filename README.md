# FFB Co-op

`FFB Co-op.exe` is one download for every co-op-modded game. Put it in the game's folder, next to
the game's exe, and start it: it updates itself, recognises the game, downloads or updates that
game's co-op mod into a `FFB Co-op` subfolder, and starts the game with the mod. Mewgenics is the
first game; a second is planned.

To uninstall, delete `FFB Co-op.exe` and the `FFB Co-op` folder next to it.

Windows only. Players who already use the standalone Mewgenics loader can keep using it.

- `docs/SPEC.md` — what the launcher does, the `games.json` format, the server layout, and the
  decisions behind them.
- `docs/agents/START.md` — how work on this repo is organised (for contributors and agent
  sessions).
